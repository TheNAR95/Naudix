# Audio editor for Android 🔊
Trim the waveform and export only the selection in M4A (AAC), MP3, WAV, or FLAC.

## Customization 🖌️
- Material You / Custom color palettes.
- Ability to select Light / Dark / AMOLED themes

## Download ⬇️
[Latest version](https://github.com/TheNAR95/Naudix/releases/latest)

## Requirements 📱
- Android 8.0 or higher
- Runs on armv7 (32-bit), arm64, and x86
